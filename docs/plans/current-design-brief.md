# Design Brief — Follow-up Question Chips & Citation Drawer Scroll Fix

**Goal:** After every assistant answer (including refusals) and the one-shot notebook intro message, show 3 clickable follow-up question chips that immediately send as the next chat message; and fix the citation side panel so long passage text scrolls instead of overflowing.

**Date:** 2026-09-14

## Shared understanding

We're adding follow-up question chips under every assistant answer in the chat — including refusals and the notebook intro/summary message — so the user always has 3 concrete next questions to click. Clicking a chip immediately sends it as a new message (unlike the existing static `WelcomeState` suggestions, which only pre-fill the input without submitting). Separately, we're fixing the citation side panel (`CitationDrawer` / `SheetContent`) so long passage text actually scrolls instead of overflowing or getting clipped.

## Key decisions

- Follow-ups are generated by extending the existing plain-text `generate()` prompt in `askQuestion` (`src/lib/generation/index.ts`) and in `notebookIntro.ts`, asking the model to emit 3 follow-up questions after the answer/summary, separated by a delimiter — no structured/JSON generation, to stay consistent with existing prompt style.
- Follow-up questions are persisted in a new `follow_up_questions` column on `messages` (new Supabase migration).
- A new `FollowUpChips` UI component (distinct from `WelcomeState`'s fill-only suggestions) renders under assistant messages that have follow-ups; clicking a chip calls the existing submit path immediately (send, not just populate the input).
- Refusal answers also get follow-up chips (suggesting alternative, better-grounded questions), always 3 per message.
- Citation drawer scroll fix: add a scrollable wrapper inside `SheetContent` (`src/components/ui/sheet.tsx`) — root-cause fix at the shared primitive, since it's a fixed-height flex column with no overflow handling and currently has exactly one consumer (`CitationDrawer`).

## Constraints

- No new "per-topic key topics" overview data model/architecture (that's a separate, larger, currently-unbuilt feature described in `docs/ARCHITECTURE.md` §7) — do not build it as part of this work.
- Keep follow-up generation in the same LLM call style already used (plain text + delimiter parsing), not a second LLM call or structured output, to minimize latency/cost and stay consistent with the codebase's existing pattern.
- Grounding rules (ADR-005) still apply to answers themselves; follow-up questions are suggestions only, not additional grounded claims.

## Out of scope

- Citation content formatting cleanup (raw chunk text rendering via `whitespace-pre-wrap`) — deferred to a later pass.
- Sentence/passage-level answer highlighting — explicitly dropped (NotebookLM doesn't have it either; would require a schema change per ADR-009).
- Building the full per-topic notebook overview feature from `docs/ARCHITECTURE.md` §7.

## Success criteria

- Every successful chat answer shows exactly 3 follow-up question chips; clicking one immediately sends it as the next user message.
- Every refusal answer also shows 3 follow-up chips with the same immediate-send behavior.
- The one-shot notebook intro/summary message also shows follow-up chips.
- The citation drawer (`CitationDrawer`) scrolls its passage content when it overflows the panel height, instead of clipping or overflowing the viewport.
- Existing `WelcomeState` static suggestions are unchanged (still fill-only, not submit).

## Expected files touched

- `src/lib/generation/index.ts` — extend `askQuestion` prompt/parsing to produce and persist follow-up questions, including on refusal path.
- `src/lib/generation/notebookIntro.ts` — extend intro generation to produce and persist follow-up questions.
- `supabase/migrations/<new>_message_follow_up_questions.sql` — add `follow_up_questions` column to `messages`.
- `src/components/chat/` — new `FollowUpChips` component; wire into message rendering (likely `chat-panel.tsx` and/or the message list component).
- `src/components/ui/sheet.tsx` — scrollable wrapper inside `SheetContent`.
- `src/components/chat/citation-drawer.tsx` — verify/adjust layout to work with the new scrollable `SheetContent`.
